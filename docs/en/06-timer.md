# 06 · "00 Timer"

[← previous](05-diagnosis-black-screen-ram.md) · [← back](../../README.md)

## What it is

A fake game ("00 Timer", "zz Timer calibrar") that shows up in the console lists (NES, GBA, etc.) and works as a countdown: pick a time, go back to the menu, play, and when it ends the "TEMPO ACABOU" alert is drawn over the game and the stick says "time's up". The timer works across the whole stick, not per console.

Timer cover art (AI-generated by the author): `assets/timer_covers/` (`gba.png`, `gb.png`, `gbc.png`, `fc.png`, `sfc.png`, `md.png`, `n64.png`, `ps1.png`, `atari.png`, `cps.png`). Per the hypothesis in chapter 02, naming the cover like the fake "game" in the console folder is enough.

## On-device scripts ("update 3")

In `scripts/timer/`, **unmodified** compared with what is on the card:

- **`hook.sh`**: if the game name does not contain "Timer", it writes `$1 $2` to `/tmp/gtimer.game` and exits with `exit 1`. If it does, it copies `timer/gtimer` to `/tmp`, runs `chmod +x`, runs it (`cal` when the name has "calibrar") with a 150 s safety kill, and logs `fim rc=...` to `hook.log`.
- **`run.sh <end_uptime>`**: sleeps in steps of up to 20 s until `uptime` reaches the end moment; then runs `gtimer alarm` and plays `timer/v/acabou.wav` twice with `aplay`.
- **`gtimer`**: ARM ELF binary of ~400 KB, **no source and not included** here. From its strings **[measured]**: in alarm mode it draws straight into the screen buffer (DRM/fb), **opens no input device** (so no button can dismiss the alert), shows "TEMPO ACABOU" for 30 s, and mentions `/sdcard/timer/aviso.txt` (which does not exist) and `/sdcard/timer/run.sh`. `gtimer` is probably what calls `run.sh` **[inferred]**.

### ⚠️ Conflict to resolve before installing

The `hook.sh` in this folder is the **timer version**. The one used for GBA games (ch. 04) launches RetroArch with `gbx_mod.cfg` through `ra_wrap.sh`. For non-Timer games the "update 3" version does `exit 1`, which **probably hands launching back to the stick's default path, without `gbx_mod.cfg`** (you would lose fast-forward) **[inferred]**. Back up your current `hook.sh` and **merge both versions** (the "Timer" branch from here + the GBA branch from there) before copying. The GBA `hook.sh` will be added to the repo later.

## Problem: the alert flickers [open]

It was once declared fixed, but later reported as **still flickering instead of staying steady**. The result of the "update 3" package was **not recorded**.

- **[hypothesis]** the flicker comes from RetroArch still drawing over `gtimer` on the same buffer.
- `kill -STOP` on RetroArch made things **worse**: the game froze ~25 s (`dtick=0`) with no sound. Reverted.
- Rewriting `run.sh` to kill `gtimer` on any button (via `evtest`) and testing `aviso.txt` were proposed; there is no confirmation they were applied.
- Without `gtimer`'s source, any fix is trial and error. The source, or the chat that produced it, would help.

## Timer inside the arcade list: given up

In arcade, the menu only lists what is in `tbl_game` of `games.db` (36 games, `gameid` 1–36; arcade: `mslug`=1, `kof97`=2, files in `game/cps/`). The folder also holds `kof97.fs` (424 B) and `mslug.fs` (480 B), dated 1979, whose purpose is **unknown**.

| Attempt | What changed | Result |
|---|---|---|
| 1 | New row with `gameid` 900 **and** a fake `00 Timer.zip` (actually a GBA ROM) | Menu hung; two changes at once, cause undetermined |
| 2 | Database only: `gameid` 37, row copied from `kof97`, names in `tbl_zh/en/tw/ko`; no `.zip` | Hung again on the loading screen |

An empty `00 Timer.fs` (0 B, created by us) was in the folder; an empty file is unlikely to break the menu, so the DB row is the most likely cause (not proof). Unconfirmed guess: the menu uses `gameid` as a position in a fixed list.

**Decision:** use the timer through the other consoles. The card was restored from `games.db.bak` and cleaned (DB with the original 36 games, no timer row, empty `.fs` removed).

If you ever try again, only with the card plugged into the PC and `games.db.bak` at hand:

```bash
S=/run/media/user/<LABEL>; DB=$S/game/games.db
cp -n "$DB" "$DB.bak"                  # backup BEFORE any change
# restore:
cp "$DB.bak" "$DB" && sync
# check:
sqlite3 -readonly "$DB" "select count(*) from tbl_game; select count(*) from tbl_game where game='00 Timer';"   # 36 and 0
```

### Using the timer with arcade

1. Open "00 Timer" on NES, GBA, etc. and pick the time.
2. Go back to the menu and open `mslug` or `kof97`.
3. At the end, the alert should appear over the game and the stick should say "time's up".
